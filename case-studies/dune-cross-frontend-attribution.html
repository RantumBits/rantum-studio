Dune Cross-Frontend Attribution Engine

Analyzing deep trace call data to uncover hidden frontend routing and user behaviors across decentralized protocols.

Andrew Maury
• Case Study

The Challenge

In the Web3 ecosystem, smart contracts are public, but the origin of the transactions is often obfuscated. When a user interacts with a decentralized exchange (DEX) aggregator, their transaction is routed through multiple intermediary contracts.

A core challenge for protocols is determining which frontend interface originated the trade. This data is critical for assigning affiliate fees, understanding market share, and optimizing routing algorithms. However, this attribution data is buried deep within execution traces, not emitted in standard event logs.

The Solution

By leveraging Dune Analytics' trace and call tables, we built an attribution engine that recursively unpacks nested smart contract calls to identify the originating frontend router.

Architectural Approach

  • Trace Analysis: Parsing trace_address arrays to reconstruct the call stack of a transaction.
  • Signature Matching: Identifying specific function selectors (e.g., swapExactTokensForTokens) embedded in calldata.
  • Spellbook Integration: Structuring the raw trace analysis into materialized views within Dune's open-source Spellbook dbt models for high-performance querying.

Example SQL Extraction

Below is a simplified example of how we extract frontend attribution codes injected into transaction calldata:

-- Extracting affiliate/frontend codes from raw calldata
SELECT 
    evt_tx_hash,
    evt_block_time,
    sender,
    -- Decode the last 4 bytes of calldata to identify the frontend router
    RIGHT(encode(call_data, 'hex'), 8) as frontend_id,
    amount_in,
    amount_out
FROM dex_protocol.router_calls
WHERE success = true
AND evt_block_time >= CURRENT_DATE - INTERVAL '30' DAY

The Impact

This attribution model successfully mapped over 85% of previously "unknown" transaction volume to specific frontend aggregators and wallets.

The insights allowed the protocol team to confidently adjust their affiliate fee structures and launch targeted incentive campaigns for their highest-performing frontend partners, directly driving a 15% increase in total volume routed through their infrastructure.
